# Como Rodar — Monte seu Carro

## 1. Verifique se tem Python instalado

Abra o terminal e rode:

```bash
python3 --version
```

Se aparecer `Python 3.x.x`, está pronto. Se não, baixe em **python.org**.

---

## 2. Instale o Streamlit

```bash
python3 -m pip install streamlit
```

Só precisa fazer isso uma vez.

---

## 3. Rode o app

```bash
python3 -m streamlit run app.py
```

O navegador abre automaticamente em `http://localhost:8501`.

---

## Para fechar

Volte no terminal e aperte `Ctrl + C`.
